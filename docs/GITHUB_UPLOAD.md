# Work with this GitHub repository

The Group 8 SMS Spam Detection repository has already been created at:

https://github.com/raneembahobail/Group8_SMS_Spam_Detection

The repository is currently private. Confirm that the course instructor has access before submitting the URL.

## Clone the repository

Install Git, then run:

```bash
git clone https://github.com/raneembahobail/Group8_SMS_Spam_Detection.git
cd Group8_SMS_Spam_Detection
```

## Push future updates

After editing or adding files in the local project folder, run:

```bash
git status
git add .
git commit -m "Describe the project update"
git push origin main
```

Do not commit downloaded datasets, temporary embedding caches, virtual environments, or other local-only files. The root `.gitignore` excludes the main runtime artifacts.

## Before sharing the submission

- Confirm the instructor can open the private repository.
- Keep the executed notebook and its relevant output cells available.
- Add the final approved project report, presentation slides, and course appendix if the instructor expects them in GitHub.
- Review whether student identifiers in the notebook should remain visible before changing repository visibility to public.
